## 三、安装方法：三步搞定，轻松上手！
### 1. 硬件连接
小精灵通过UART1与飞控的串口1“牵手”，连接方式如下：

•	5V（小精灵） ↔ 5V（飞控）

•	GND（小精灵） ↔ GND（飞控）

•	io04（小精灵） ↔ RX1（飞控）

•	io05（小精灵） ↔ TX1（飞控）
#### 小贴士：

•	为了兼容性，强烈推荐用飞控的Serial Port 1。

•	测试过Serial Port 6也能用，但其他串口没试过，可能会有“惊喜”哦！
### 2. 飞控设置
1.	打开地面站软件（推荐Mission Planner）。
2.	进入初始设置 → 必要硬件 → Serial Ports。
### 3.	将Serial Port 1设置为：
o	波特率：115200

o	协议：MAVLink2
### 4.	保存设置，重启飞控。
  

#### 找不到设置页面？别慌！
•	打开配置调试 → 全部参数表，搜索“serialX”,如果配置的是1号端口，输入"Serial1"

•	输入波特率和协议参数，点击写入参数，再重启飞控即可。
  
### 4. 验证安装：成功与否，一看便知！
安装好后，用以下方法检查小精灵是否“上线”：
#### 1.	地面站验证：
o	打开Mission Planner的飞行数据 → 消息页面。

o	小精灵会发送消息，通常是“等待本机GPS定位信息”
  
#### 2.	WiFi验证：
•	打开手机WiFi，搜索以TeamXXXX开头的信号。

•	找到这个WiFi？恭喜，小精灵已经成功就位！

## 四、异常排查：小问题也能轻松搞定！
如果小精灵“闹脾气”，别急，试试以下方法：
1.	检查硬件连接：
o	逐一检查连接线，确认没有松动或虚焊。
o	确保5V、GND、TX、RX线都连接得“稳稳当当”。
2.	互换RX/TX线：
o	还是不行？把RX和TX线换个位置试试，可能会“柳暗花明”！
3.	检查地面站设置：
o	确认波特率是115200，协议是MAVLink2。
o	确保选对了串口（推荐Serial Port 1），其他串口可能不“给力”。

	编队高度：僚机比你高20厘米？还是低点？正数高，负数低，随你定！

#### 3.	查看僚机状态：

## 六、编队起飞：准备好，飞向天空！
### 1. 领航机起飞
•	检查GPS：确保GPS卫星数大于6颗，信号稳稳的！

•	解锁起飞：按照正常流程解锁，起飞一气呵成！

•	地面站加持：如果有地面站数传，还能看到小精灵的实时状态信息，飞得更安心！

### 2. 僚机起飞
•	检查GPS：同样确保卫星数大于6颗

•	解锁起飞：正常起飞后，保持在200米范围内，WiFi连上领航机

•	切换模式：ArduPilot固件：切换到Guided模式。

##### 只要WiFi连得上，即使领航机已在空中，僚机也能自动加入编队，超智能！

## 七、编队飞行注意事项：安全第一，快乐飞行！
1.	飞行姿态：领航机要飞得稳，急转弯可能会让僚机“跟不上节奏”
3.	空域环境：确保飞行区域开阔，无遮挡物干扰。
4.	安全飞行：
o	不要低空飞越建筑物、树林或桥洞，安全第一！
o	飞行高度不得低于3米，否则僚机自动解除编队，进入RTL模式返回起点。
5.	距离限制：领航机与僚机距离别超200米，超限会解除编队，返回起飞点。
6.	信号要求：WiFi信号要保持畅通，一旦断开，僚机也会自动返回起点。
7.	编队规模：由于芯片算力有限，当前版本仅支持双机编队。想三架或更多飞机一起飞？请联系我们获取更多支持！
