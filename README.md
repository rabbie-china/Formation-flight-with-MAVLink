# 伴飞小精灵编队系统说明书
伴飞小精灵编队系统（Flying Companion Formation System），专为热爱航模的新手朋友们打造。它安装在航模飞控上，利用 esp32 芯片连接飞控串口，实现全自动航模编队飞行，让你的每一次飞行都能成为一场令人惊叹的视觉盛宴。
### 一、产品功能
本系统通过 esp32 芯片与飞控串口相连，轻松实现航模的编队飞行。你可以自由设置长机和僚机，系统支持多种炫酷的编队类型，还能根据你的想法调整编队飞机之间的距离和高度，让你的航模编队飞行更加个性化。
### 二、按键说明
在我们的系统里，IO02 就是那个神奇的按键。如果你想解除僚机编队设置，只需要从 IO02 端口引出一根线，让它接地，就能轻松搞定啦。
### 三、与飞控的连接方法
#### 硬件连接
1.	首先要根据飞控型号和实际使用情况，选择飞控的特定串口，比如串口 3 或串口 4。
2.	将 IO04（RX）连接到飞控的 TX 端口，这就像给它们搭建了一条接收数据的通道。
3.	把 IO05（TX）连接到飞控的 RX 端口，这样就能发送数据啦。
4.	把 5v 连接到飞控的 5v 端口，为设备供电。
5.	最后，将 GND 连接到飞控的 GND 端口，确保电路的稳定。
#### 参数设置
1.	把波特率调整为 115200，这是数据传输的速度哦。
2.	端口选择 “MAVLink2” 或者 “MAVLink” 协议，这是它们之间沟通的语言。
3.	完成以上设置后，一定要记得保存，这样设置才会生效。
### 四、支持的飞控固件
我们的伴飞小精灵编队系统支持 ap 和 inav 这两种飞控固件，兼容性超棒。
### 五、测试连接
#### 正常情况
当飞控和 esp32 之间通讯正常时，你会看到两个灯欢快地闪烁，这就表示它们已经成功 “牵手” 啦。
#### 异常排查
1.	先仔细检查一下连接的线，看看有没有松动或者虚焊的地方，小小的松动可能会导致大大的问题哦。
2.	如果还是不行，那就把 rx 线和 tx 线互换一下，说不定就能解决问题。
3.	最后，检查一下地面站的设置，是不是串口速率或者协议，哪里不小心设置错啦。
要是一切都正常，接下来就打开你的手机，搜索 Team 开头的热点。每块 esp32 的热点都不太一样，比如 TeamF09B，后面还会跟着 4 个数字，密码都是 123456789，可别输错啦。
### 六、长机设置
#### 基础设置
你可以给自己的长机取一个超酷的昵称，例如“我是领航鲸”，然后打开 “我要做长机，我要启动 AP 热点”的选项，让你的长机成为编队的 “领头羊”。
#### 编队设置
在编队类型里，有各种各样的队形编队任你挑选。你还能自由设置编队飞机之间的距离和高度。比如说，你想让僚机在长机后面 1 米，比长机高 20 厘米编队，那就把编队距离设置为 100 厘米，编队高度设置为 20 厘米。要是你把高度设置成负数，僚机就会比长机飞的低啦。
#### 僚机信息查看
当有僚机连接上来，你就能在长机上看到僚机的编号、昵称和连接状态，随时掌握编队小伙伴的情况。
### 七、僚机设置
#### 基础设置
首先要关闭 “我要做长机，我要启动 AP 热点”的选项，然后把长机的 WIFI 设置为编队长机的 wifi，热点密码是 123456789，不用更改哦。设置好后点击保存并重启。以后每次上电，僚机就会自动去寻找长机。要是你想解除设置，按一下 esp32 的 IO02 按键（接地），就能恢复到原来的设置啦。
#### 增加飞行模式
如果你的飞控固件是 ap，就增加 guided 模式；要是 inav，就增加 “Waypoints” 模式，这样就能轻松切换到编队飞行模式啦。
### 八、编队起飞
#### 长机编队起飞
起飞前，一定要检查一下 gps 卫星数量，一般要多于 6 颗星才行。确认没问题后，就可以正常解锁起飞啦。要是你配备了地面站数传，那就更牛逼了，能从地面站信息看到esp32 输出的状态信息，让你随时了解飞行情况。
#### 僚机编队起飞
和长机一样，先检查 gps 卫星数量多于 6 颗星，然后正常解锁起飞。起飞后，只要在 200 米范围内，并且 wifi 能连接上长机，把模式切换一下（ap 固件切换成 guided 模式，inav 固件切换成 “Waypoints” 模式），就能自动跟随编队飞行啦。即时长机在天上飞行，只要能连接上长机的wifi，也能自动编队。
### 九、编队注意事项
1.	飞行姿态：长机飞行的时候一定要保持稳定，千万不要急转弯，不然僚机可能会 “跟不上节奏”。
2.	空域环境：要保证编队空域没有遮挡物，
3.	安全飞行：不要低空飞越建筑物，不要低空穿越密集的树林或者水面桥洞
4.	高度限制：飞行高度不能低于 3 米，不然僚机就会自动解除编队，切换成 rtl 模式自动返回起点。
5.	距离限制：长机和僚机的距离一般不能超过 200 米，超过了就会解除编队，然后返回起飞点。
4.	信号要求：长机和僚机的 wifi 信号一定要保持连接，断开的话僚机也会自动解除编队并返回起飞点。
### 总结
伴飞小精灵编队系统为新手航模爱好者打开了编队飞行的大门，只要按照这份说明书，一步步完成连接、设置和操作，你就能轻松体验到航模编队飞行的乐趣。在操作过程中，一定要仔细检查每一个步骤，注意飞行安全。希望大家都能通过伴飞小精灵编队系统，创造出属于自己的精彩飞行瞬间，享受航模带来的无限魅力 。
